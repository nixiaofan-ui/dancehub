## 一、上线前必做

> ⚠️ **这一节全部在「小程序后台」(`mp.weixin.qq.com`) 操作，不在云托管控制台**
> (`cloud.weixin.qq.com`)。后者只管服务器、数据库、版本发布。两个后台容易混。

### 1. 用户隐私保护指引：增加「剪贴板」

不做：`wx.setClipboardData` 在正式 appid 下直接 fail，报
`setClipboardData:fail api scope is not declared in the privacy agreement`，
表现为「点了复制毫无反应」（现在代码已经会弹提示 + 打日志，但功能仍不可用）。

两个入口，任选其一（内容一样）：

- **入口 A（推荐）**：登录 `mp.weixin.qq.com` → 左侧菜单「**设置**」→「基本设置」
  → 往下拖到「**服务内容声明**」→「用户隐私保护指引」→ 点「**更新**」
- **入口 B**：鼠标移到**左下角头像** → 「账号设置」→ 「服务内容声明」

进去之后：**增加信息类型 → 勾选「剪贴板」→ 填用途 → 确定并生成协议**。

用途文案（照抄即可）：

```
用于复制舞室名称，方便用户前往该舞室的官方小程序完成预约
```

提交后需**审核通过才生效**（无需重新上传小程序，重启小程序即可）。
若体验版仍失败，去「版本管理 → 体验版 → 提交审核」页面底部的
「用户隐私保护指引设置」再更新一次 —— **未发布上线的小程序只有这个入口生效**。

### 2. 模糊定位：接口权限 + 隐私指引

不做：`wx.getFuzzyLocation` 直接 fail，定位按钮只会提示「定位失败」。

1. 小程序后台 → 开发 → 开发管理 → **接口设置** → 自助开通「获取模糊地理位置」
2. 用户隐私保护指引 → 增加信息类型 → 勾选「**位置信息**」

用途文案：

```
用于获取用户所在城市，自动展示当地舞室的课表
```

> 用模糊定位（getFuzzyLocation）而不是精确定位（getLocation）：
> 我们只需要城市粒度，精确位置属过度索取且类目多半申请不下来；
> 二者在 `app.json` 的 `requiredPrivateInfos` 里**互斥**，只能声明一个。

### 3. 上传体验版 / 提交审核

`app.json` 改了（新增 `requiredPrivateInfos`、`permission`），小程序代码必须
重新上传才会生效。微信开发者工具 → 上传 → 后台设为体验版。

## 二、云端自动抓取（方案 B）

代码已就绪（并发 + 时间预算 + 出口连通性自检）。三处配置，**已核实的状态如下**：

| # | 位置 | 操作 | 状态 |
|---|---|---|---|
| 1 | 云托管 → 服务 → dancehub-server → 服务设置 → 公网访问 | 打开 | ✅ **已开**（2026-09-27 12:03 实测可访问） |
| 2 | 云托管 → 服务 → 服务设置 → 实例副本数 | 最小设为 **1** | ✅ 已设（截图确认为 1 / 最大 5） |
| 3 | 云托管 → 服务 → 服务设置 → 环境变量 | 把 `SKIP_CRAWLER` 改成 `0`（或删掉），并加 `CRAWL_MODE=scheduler` | ❌ **还差这一步** —— 线上自检回报 `crawlMode: off` |

第 3 步改完，容器重启后生效。**不要用 CLI 的 `--envParams` 传**：它会全量覆盖，
我们读不到现有变量清单（`service:list` 不返回环境变量），一旦把 `DATABASE_URL`
冲掉就是全站宕机。在控制台里改是可见、可回滚的。

### 怎么验证有没有生效（一条 curl）

```
curl -s https://dancehub-server-317678-10-1493161376.sh.run.tcloudbase.com/api/crawler/probe
```

返回里的 `mode.crawlMode`：

- `scheduler` → ✅ 已在自动抓取。每 6 小时补抓一次，587 家约 3 分钟跑完
- `off` → ❌ 环境变量还没生效（当前就是这个状态）
- `trigger` → 等定时触发器调 `/api/crawler/tick`（本项目的备选方案）

同一响应里的 `results` 是**出口连通性实测**，2026-09-27 12:10 的结果：

```json
{"generic":{"ok":true,"status":200,"ms":69},
 "aiwugong":{"ok":true,"status":200,"ms":158}}
```

**两项都通** —— 容器能出公网，也能直连爱舞功课表接口。
所以「云端出不去公网」不是当初关掉云端抓取的原因，方案 B 成立。

回退：出网若哪天不通了，把 `SKIP_CRAWLER` 改回 `1`、最小副本数改回 `0`，
数据继续走「本机抓取 + `server/scripts/sync_cloud_db.sh` 推云库」。

> 公网那个默认域名只用于**我们调试**（浏览器访问有时效，到期点「点击续期」）。
> 小程序走的是 `wx.cloud.callContainer`，不经过域名，所以不绑自定义域名也能上线。

## 三、可选优化

### 逆地理定位（更准）

现在「定位 → 城市」用的是**最近城市中心点**算法（离线坐标表，无需任何 key）。
在广佛、深莞这类相距不到 30km 的城市群边界上可能判错（比如佛山判成广州），
用户可在城市条上手动纠正。

要更准：去 [腾讯位置服务](https://lbs.qq.com) 申请 key，在云托管环境变量里加

```
TENCENT_MAP_KEY=你的key
```

服务端会自动改用逆地理编码，无需发新版小程序。
