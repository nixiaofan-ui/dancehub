### 1. 用户隐私保护指引：增加「剪贴板」

不做：`wx.setClipboardData` 在正式 appid 下直接 fail，报
`setClipboardData:fail api scope is not declared in the privacy agreement`，
表现为「点了复制毫无反应」（现在代码已经会弹提示 + 打日志，但功能仍不可用）。

两个入口，任选其一（内容一样）：

- **入口 A（推荐）**：登录 `mp.weixin.qq.com` → 左侧菜单「**设置**」→「基本设置」
  → 往下拖到「**服务内容声明**」→「用户隐私保护指引」→ 点「**更新**」
- **入口 B**：鼠标移到**左下角头像** → 「账号设置」→ 「服务内容声明」

进去之后：**增加信息类型 → 勾选「剪贴板」→ 填用途 → 确定并生成协议**。

用途文案（照抄即可）：

```
用于复制舞室名称，方便用户前往该舞室的官方小程序完成预约
```

提交后需**审核通过才生效**（无需重新上传小程序，重启小程序即可）。
若体验版仍失败，去「版本管理 → 体验版 → 提交审核」页面底部的
「用户隐私保护指引设置」再更新一次 —— **未发布上线的小程序只有这个入口生效**。

### 2. 模糊定位：接口权限 + 隐私指引

不做：`wx.getFuzzyLocation` 直接 fail，定位按钮只会提示「定位失败」。

1. 小程序后台 → 开发 → 开发管理 → **接口设置** → 自助开通「获取模糊地理位置」
2. 用户隐私保护指引 → 增加信息类型 → 勾选「**位置信息**」

用途文案：

```
用于获取用户所在城市，自动展示当地舞室的课表
```

> 用模糊定位（getFuzzyLocation）而不是精确定位（getLocation）：
> 我们只需要城市粒度，精确位置属过度索取且类目多半申请不下来；
> 二者在 `app.json` 的 `requiredPrivateInfos` 里**互斥**，只能声明一个。

### 3. 上传体验版 / 提交审核

重新上传才会生效。微信开发者工具 → 上传 → 后台设为体验版。

## 三、可选优化

### 逆地理定位（更准）

现在「定位 → 城市」用的是**最近城市中心点**算法（离线坐标表，无需任何 key）。
在广佛、深莞这类相距不到 30km 的城市群边界上可能判错（比如佛山判成广州），
用户可在城市条上手动纠正。

要更准：去 [腾讯位置服务](https://lbs.qq.com) 申请 key，在云托管环境变量里加

```
TENCENT_MAP_KEY=你的key
```

服务端会自动改用逆地理编码，无需发新版小程序。
