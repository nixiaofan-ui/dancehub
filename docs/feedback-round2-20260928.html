发现 → 顶部「自选组合」› 搜门店名 → 勾选（2–12 家）› 底部「开始对比」
  • 选完进的就是多店课表：上方门店 chip 可随时增减，下方课表实时跟着变。

2. 分店没汇总成品牌MAX POWER STUDIO 等

品牌聚合认两种分店写法
已修复
「max power studio 现在仍显示三家分门店」

品牌的识别规则原来只认 品牌·分店 里的「·」，而 MAX POWER STUDIO（汶水路店） 这种用括号写分店名的老数据被当成了三家独立门店。现在「·」和「（分店）」都认， 并且自动排除「（点击有地图指引）」这类营销尾巴。

城市修复前品牌数修复后回到品牌条的
上海（实测）913MAX POWER STUDIO（3 家）、麦田舞蹈星舞会、上海雅琴钢管舞蹈、至燥街舞
注：品牌条只收「同城 ≥2 家门店」的品牌，单店不重复占位置。

3. 老师主页：改成「过去一周排课」

未来两周 → 上周规律 + 未来可约
已上线
「一般舞室不会公布未来两周的课表，或许可以参考上周的课表」

你判断得对。现在老师主页主视图是「上周排课规律」：按周几归并， 每节课标出 时间 · 门店 · 课程名；未来真有可约的课，放在下面「接下来能约」区块。

  • 顶部一句话：过去一周在 N 家舞室上过 M 节课。
  • 库里保留历史课（最早到 2026-07-31），实测一位上海老师过去一周能查到 11 节、跨 2 家店 —— 这类信息才是「他固定周几在哪上课」的答案。
  • 未来课表常年为空的舞室，底部会直接说明「还没放出未来的课，按上面的规律去蹲就行」， 不再显示成 0 节让人以为数据没抓到。

4. 屏蔽老师：发现页的课表没生效

补上过滤，并折叠成一行
已修复
「你可能做的是 tabbar 里的「课表」，不是「发现-品牌-课表」里的「课表」」

完全正确 —— 屏蔽名单当时只挂在底部 tab 的「课表」页，「发现 → 品牌 → 课表」这张表根本没读名单。 现在两处一致，并且按你说的做成折叠成一行，而不是让课彻底消失：

课表底部 已隐藏「XX」的 3 节课·点「展开」可临时查看
为什么留一行：课直接消失的话，用户会怀疑「是不是这家店今天没课 / 数据没抓到」， 无法确认屏蔽到底生效没有。留一行既证明生效，也给了反悔入口。

6. 门店不完整：嘉禾马家堡店

当天没课的门店不再漏
已修复（13/13）
「北京的嘉禾舞室的马家堡店就不在里面」

原因找到了：嘉禾的课表接口只返回当天有课的门店（13 家里今天只有 6 家有课）， 马家堡店 2026-09-14 才开、当天没排课，于是库里查无此店。现在改成 先按门店档案建全量 13 家，课为 0 也留一条记录（点进去显示「暂无排课」）。

  • 抓取时建店 + 服务启动时再自愈一次（幂等），云端库里的存量缺口会自动补上。
  • 本地实测：13 家齐全（北京 8 / 天津 / 邯郸 …），删掉一家后重启会自动补回。
其它平台（iWOD / 菲体云 / 爱舞功）没有公开的门店档案接口， 只能靠「有课才建店」，这类缺口仍在，靠每天抓取慢慢覆盖。
