四、方法与边界

为什么不是小红书。小红书正文没有可抓取的结构化榜单接口，只能靠搜索结果拼， 得到的排名噪声大、且分不清「广告」和「口碑」。改用高德 POI 榜单 ranks.amap.com/ranking/…，服务端渲染 + JSON-LD，给出的是真实用户行为排出来的榜。
平台能否全量枚举怎么找
菲云 fityun能，2177 家 capture/fityun-orgs.jsonl，含名称 / 地址 / 电话 / 坐标
iWOD能，1985 家有档案 boxes-all.jsonl 只有 boxId，需 build_iwod_catalog.py 反查 getCurrentBoxInfo 才有名字
爱舞功能，682 家 studios.aiwugong.json，自带 studio.city
styd半可枚举只能按经纬度网格扫 nearby_shop_list，覆盖稀疏
csdsp不能tenantId 不连续，跳号就 500，只能解 wxapkg
gsteps / 嘉禾 / 狐舞 / 飞兔 / rawgraphy— 基本是自营品牌，一家一条配置
上海、郑州是例外。这两座城市高德没有市级舞蹈榜（所有类目 × 所有行政区都返回 404）， 所以名单是人工搜出来的，置信度比其它 18 城低。相应地改用更硬的办法补： 以城市中心画 60km 坐标框全量捞菲云机构 → 店名筛掉瑜伽 / 琴行 / 球类 → 回源试 7 天课表，有课才接。

结论是上海「榜上有名」的品牌（BodySoul、CASTER、单色、舞邦 SINOSTAGE、Fancy、银琪、邱艳） 全都不上任何一家 SaaS —— 它们是上海最有名的一批，但恰好都在我们半径之外。 反倒是坐标扫出来的一批中型舞室能接，这轮补了 6 家。
